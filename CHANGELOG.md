# Changelog

## Unreleased — portable task workbench

- Add source-bound `tools`, `context`, `scan` and `construct` entry points.
  The chemistry supplied-function constructor derives word widths from
  registers, checks both actual endpoints and preserves prior phase/history.
- Add bounded-memory width invoices and exact single-product loan censuses.
  The latter does not construct a joint schedule or a narrower KMB.
- Add an exact typed chemistry constraint checker for mask/F/B/composed-G
  targets, including the optional low-address table. Keep optimization
  runtimes and whole-task admission external.

  standalone phase or whole-task prover. Credit team ThemBones' published
  algebra and relation contracts; no source data ships in the package.
- Stream hashes and preserve charged candidates beyond free-operation noise.
  Refusals retain receipts without overwriting existing output directories.


## 0.3.0 — 18 November 2026

- Rat admission v2 combines all-legal-input bit-sliced checks under zero/7/101,
  cumulative dirty-reset accounting, parent-bound activating-subspace checks,
  and engine reproduction of the default-salt official cost schedule. Skipped,
  unknown or unactivated changed guards cannot pass the transition screen.
  Outcomes remain finite samples; this is not an all-history proof. Existing
  streaming diagnostics keep their original semantics. New acceptance contexts
  require fresh run directories.
- `census` and `rank_liveness` expose source-bound live-value GF(2) ranks, with
  the constant column included for affine dependence. Full rank filters free
  affine recovery; it does not exclude a paid nonlinear rebuild. Sampled
  relations require validation before construction.
- Credit crackercoder (Sazzad) for suggesting stronger admission and a rank
  liveness census in Kaggle discussion 755075. No code from that team was
  imported. The activating-subspace helper is vendored from this project's
  Claude/P pathway (`scripts/qhdl_alloutcome.py`), with R additions for dirty
  reset counts, task audits and conservative coverage handling.

Real-circuit calibration and limits: [admission and census](docs/ADMISSION_AND_CENSUS.md).

- Publish the validated portable component workbench: reversible, dense quadratic
  and measured proofs, disjoint-body retiming, phase-demand construction and
  bounded same-width assembly. Package-relative imports replace research paths;
  independent scalar and fault controls ship with the code.
- Add `ssr-components`, authored examples and a discoverable component guide.
  Generic component support does not imply DQI/chemistry task verification.
- Add dependency-light `ssr-rat doctor` and help, actionable native dependency
  failures, NumPy>=2 requirement, synchronized package versions, hashed uv
  development dependencies and public portable-test CI.
